타임리 Agent Playbook 별지

본 문서는 Making AI Beneficial 챌린지 참가자 운영 안내입니다. 제품 기능이 아닌 대회 운영 기준이며, 최종 내용은 운영진 공지를 따릅니다. 제품 사용법은 별도 문서 「타임리 Agent Playbook」(이하 본편)을 참조합니다.

PART 0

0. 대회 스페이스 접속 확인

타임리에 접속하면 기본으로 Timely AI 스페이스가 열립니다. 대회 과제는 Making AI Beneficial Challenge 스페이스 에서 수행해야 합니다. 스페이스마다 크레딧·스킬·자동화가 분리되어 있으므로, 작업을 시작하기 전에 현재 스페이스를 먼저 확인합니다.

왼쪽 사이드바 맨 아래의 사용자 이름을 선택하면 스페이스 목록이 표시됩니다. 목록에서 Making AI Beneficial Challenge 스페이스 를 선택합니다.

그림 0-1. 사이드바 하단의 사용자 이름 선택 → 스페이스 목록 → Making AI Beneficial Challenge 스페이스

⚠️ 다른 스페이스에서 작업하면 대회에 반영되지 않습니다

Timely AI 스페이스 를 비롯한 다른 스페이스에서 작업하면 대회 크레딧이 차감되지 않으며, 생성한 스킬과 자동화도 대회 스페이스에 나타나지 않습니다. 과제가 보이지 않거나 크레딧이 줄지 않는다면 가장 먼저 스페이스를 확인합니다.

PART 1

1. 크레딧 확인

  • 예선 기간 동안 사용할 크레딧이 지급됩니다. 지급량은 운영진 공지를 확인합니다.
  • 지급된 크레딧을 모두 사용한 경우 추가 지급을 신청할 수 있습니다.

잔액은 설정 → 크레딧 현황에서 확인합니다.

그림 1-1. 설정 → 충전/결제 관리 → 크레딧 현황
항목내용
스페이스 크레딧 (관리자 소유)대회에서 지급되는 크레딧으로, 참가자가 사용하는 크레딧입니다
└ 총 크레딧 · 사용량 · 남은 잔여량"남은 잔여량" 이 확인 대상 항목입니다
└ 월별 리셋형매월 초기화되는 방식입니다

현재 사용 중 크레딧적용 중인 크레딧을 표시합니다. 스페이스 크레딧이 활성 상태여야 합니다

💡 사이드바에서도 확인할 수 있습니다

왼쪽 사이드바 하단의 스페이스 크레딧 게이지에 마우스를 올리면 총 크레딧 · 사용량 · 남은 잔여량 이 함께 표시됩니다. 설정 화면으로 이동하지 않고 확인할 때 사용합니다.

💡 잔액 확인 시점

스킬 제작이나 대규모 웹 조사와 같이 소모가 큰 작업 이후에는 잔여량을 확인합니다. 잔여량을 파악해야 이후 작업 범위를 판단할 수 있습니다.

PART 2

2. 모델 사용 규칙

대회에서는 Solar Pro 4 만 사용합니다. 본편 2-2에서 설명한 것과 같이 모델 선택 목록에는 여러 계열의 모델이 표시되지만, 대회 과제를 수행할 때는 채팅과 자동화 모두 Solar Pro 4로 지정해야 합니다.

또한 스킬이나 자동화 코드에서 외부 LLM API를 호출하는 방식은 허용되지 않습니다. 외부 사업자의 언어 모델 API를 직접 호출해 결과를 생성하는 구성은 제출 대상에서 제외됩니다.

구분허용 여부
채팅·자동화의 모델을 Solar Pro 4 로 지정허용
그 외 모델 선택불가
스킬·자동화 코드에서 외부 LLM API 호출불가
공공데이터·외부 서비스 API 호출 (언어 모델이 아닌 경우)허용

⚠️ 제한은 선택 여부와 무관하게 적용됩니다

대회 스페이스에는 사용 가능한 모델과 도구가 지정되어 있습니다. 모델 선택 목록이나 도구 목록에서 다른 항목을 고르더라도 실제로는 사용되지 않습니다. 목록에 표시된다는 것이 사용 가능하다는 의미가 아니므로, 과제는 허용된 범위 안에서 구성해야 합니다 (본편 2-2).

PART 4

4. 크레딧 절약 방법

  1. 주제가 변경되면 새 대화를 시작합니다. 대화가 길어질수록 이전 내용이 매번 함께 처리되어 소모량이 누적됩니다.
  2. 공식 문서 처리 스킬을 설치한 후 사용합니다. (스토어 → 스킬 → 공식 필터, 본편 4-2)
  3. 문서는 캡처 이미지가 아닌 원본 파일로 업로드합니다.
  4. 추론은 필요한 경우에만 조정합니다. (본편 2-3)
  5. 사용하지 않는 스킬은 토글을 비활성화합니다. (본편 4-2)
  6. 종료된 자동화는 스케줄을 정지합니다. (본편 4-4)
  7. 산출물은 종료 전에 보관합니다. 작업 공간이 정리된 뒤 다시 생성하면 크레딧이 중복 소모됩니다. (본편 3-2)
PART 5

5. 오류 대응

상황대응 방법
작업이 중단되거나 오류로 종료된 경우이어서 계속해줘 를 입력하면 재개됩니다. 처음부터 다시 실행하지 않습니다
스킬 생성에 시간이 소요되는 경우10~20분이 소요될 수 있습니다. 모델이 실행·검증을 수행하는 시간입니다
긴 프롬프트가 분할 전송되는 경우입력창에서 Enter 는 전송입니다. 한 번에 붙여넣기 합니다 (본편 2-1)
생성한 스킬이 표시되지 않는 경우AI 채팅이 아닌 에이전트 탭인지 확인합니다 (본편 0장). 탭이 맞다면 스킬로 다시 만들어 달라고 요청합니다
모델·추론을 변경할 수 없는 경우도구·파일 준비 중 표시가 사라질 때까지 대기합니다 (본편 2-1)
자동화 이름을 변경하려는 경우name 은 저장 후 변경할 수 없으므로 새로 생성해야 합니다 (본편 6-2)
에이전트가 특정 도구를 사용하지 않는 경우tools 화이트리스트 포함 여부를 확인합니다 (본편 6-3)
